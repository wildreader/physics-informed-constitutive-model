## 1. 环境、数据与快速运行

以下命令均从项目根目录执行。

### 1.1 准备 Python 环境

项目依赖 PyTorch、NumPy、SciPy、scikit-learn 和 Matplotlib。可使用 Python 3.10 或更高版本建立虚拟环境；当前仓库未提供依赖版本锁定文件。

```bash
python -m venv .venv
```

激活环境：

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```bash
# Linux / macOS
source .venv/bin/activate
```

安装依赖：

```bash
python -m pip install torch numpy scipy scikit-learn matplotlib
```

使用 GPU 时，环境需要安装与本机驱动兼容的 CUDA 版 PyTorch。默认 `--device auto` 会在 CUDA 可用时使用 GPU，否则使用 CPU；也可显式指定 `--device cpu` 或 `--device cuda`。

### 1.2 准备数据

数据由 MATLAB 生成。如果已有与当前代码匹配的六份 MAT 文件，可直接进入训练步骤；重新生成数据时，在 MATLAB 中将工作目录切换到项目根目录并运行：

```matlab
run('matlab_data_generation/generate_all_datasets.m')
```

生成目录：

```text
matlab_data_generation/generated/
├── free_energy/
│   ├── train_7cases.mat
│   └── test_5cases.mat
├── free_energy_damage/
│   ├── train_7cases.mat
│   └── test_5cases.mat
└── full/
    ├── train_7cases.mat
    └── test_5cases.mat
```

默认采用 110 个 Lebedev 方向、加载步长 `0.01` 和损伤耦合系数 `alpha=0.5`。前两种数据为严格等体积路径 `J=1`；`full` 数据加入体积变化与压力响应。

训练阶段必须与数据匹配：自由能阶段读取 `free_energy`，损伤阶段读取 `free_energy_damage`，体积阶段读取 `full`。程序会检查架构元数据、张量形状、体积比，以及阶段之间的积分方向、权重和参考尺度。

### 1.3 训练模型

运行完整三模块顺序训练：

```bash
python train4.py --architecture full
```

仅训练自由能，或训练自由能与损伤：

```bash
python train4.py --architecture free_energy
python train4.py --architecture free_energy_damage
```

默认结果保存到 `outputs/<architecture>/`。

### 1.4 预测与评估

```bash
python pred2.py --architecture full
```

预测配置必须与检查点匹配。评估过程会读取该配置对应的训练 MAT 文件、测试 MAT 文件和检查点；训练文件用于提供积分方向、权重等信息。程序输出测试集总应力 MSE、六个分量的 RMSE，并保存预测数据与五工况对比图。

其他配置使用对应命令：

```bash
python pred2.py --architecture free_energy
python pred2.py --architecture free_energy_damage
```

### 1.5 快速检查完整流程

每阶段仅运行 1 个 epoch，并保存到独立目录：

```bash
python train4.py --architecture full --free-energy-epochs 1 --damage-epochs 1 --volumetric-epochs 1 --output-dir outputs/smoke_full
python pred2.py --architecture full --checkpoint outputs/smoke_full/model.pth --output-dir outputs/smoke_full/prediction
```

## 2. 模型架构、网络层数与力学数据流

仅有一个 `ModularConstitutivePINN`，内部始终包含三个模块。`--architecture` 控制最终启用组合；三种配置的参数结构和参数名相同，关闭的模块仍保留在模型及检查点中。每次训练只创建一个模型，各阶段切换数据、模块开关和优化器。

### 2.1 网络结构与层数

**局部特征网络为 `1-32-32-6`，自由能/损伤预测器为 `12-64-64-1`，体积网络为 `1-32-32-1`。**

下表按 `nn.Linear` 计层，不把输入、激活函数、池化或解析物理运算计为线性层。

| 模块 / 子网络 | 结构 | 线性层数与隐藏层 | 激活与输出 |
| --- | --- | --- | --- |
| 自由能局部提取器 `free_energy_module.extractor` | `1 → 32 → 32 → 6` | 3 层；2 个 32 宽隐藏层 | 前两层后为 Softplus；输出 6 维局部特征 |
| 自由能预测器 `free_energy_module.predictor` | `12 → 64 → 64 → 1` | 3 层；2 个 64 宽隐藏层 | 每层后为 Softplus；输出非负方向自由能 φ |
| 损伤局部提取器 `damage_module.extractor` | `1 → 32 → 32 → 6` | 3 层；2 个 32 宽隐藏层 | 前两层后为 Softplus；输出 6 维局部特征 |
| 损伤预测器 `damage_module.predictor` | `12 → 64 → 64 → 1` | 3 层；2 个 64 宽隐藏层 | 前两层后为 Softplus，末端 Sigmoid；输出损伤 d |
| 体积自由能 `volumetric_module` | `1 → 32 → 32 → 1` | 3 层；2 个 32 宽隐藏层 | 前两层后为 Softplus；末端线性输出 U_vol |

自由能、损伤模块各含 6 个线性层，体积模块含 3 个，完整模型合计 15 个。自由能与损伤结构相似但参数独立；**同一模块的局部提取器在所有积分方向上共享参数。**

### 2.2 局部与全局特征如何组合

设批大小为 B、积分方向数为 D（默认 110）。自由能输入是当前方向伸长，损伤输入是已给定的历史最大方向伸长，两者均为 `[B,D]`。

```text
方向标量 [B,D]
  → 输入归一化
  → 共享局部网络 1→32→32→6
  → 局部特征 [B,D,6]
  → 按 Lebedev 权重对方向求和，得到全局特征 [B,1,6]
  → 将全局特征广播到每个方向，与局部特征拼接 [B,D,12]
  → 预测器 12→64→64→1
  → 方向自由能 φ 或损伤 d [B,D]
```

预测器的 12 维输入来自“6 维局部 + 6 维全局”，不是 12 个应变分量。

### 2.2.1 参数共享：覆盖所有方向、样本和 batch

**是的，同一分支的特征提取器参数在所有方向、一个 batch 的全部样本以及不同 batch 之间共享。** 更准确地说，输入是方向伸长比 λ（自由能分支）或历史最大方向伸长比 λ_max（损伤分支），不是直接输入应变张量。工程应变可写为 λ-1，但当前代码实际使用的是归一化后的伸长比。

设 b 为样本编号、a 为方向编号，同一分支的局部特征为：

```text
h_ba = f_theta(x_hat_ba) ∈ R^6
```

所有 `(b,a)` 都调用同一个 `f_theta`，不会为每个方向或每个样本单独创建网络。代码把 `[B,D]` 展开为 `[B×D,1]`，一次送入共享提取器，再恢复为 `[B,D,6]`。同一分支的预测器也在所有样本和方向上共享参数。不同 batch 继续使用同一组参数，训练时每次 optimizer.step() 更新这组参数；“共享”不表示参数在训练期间保持不变。

共享的是映射规则，不是输出数值：不同伸长通常得到不同的 6 维特征；这些特征是学到的隐变量，不预先对应六个应力分量。自由能与损伤分支各有独立的提取器和预测器，二者不共享权重。一个 batch 中的样本共同贡献当前分支参数的损失梯度，但前向计算不会把不同样本的特征混在一起。

### 2.2.2 DeepSets：方向池化的不变性与方向输出的等变性

DeepSets 的基本思路是“共享逐元素映射 + 对称聚合 + 后续映射”，用于处理元素排列不应影响集合输出的问题，参见 [Zaheer 等，Deep Sets（2017）](https://arxiv.org/abs/1703.06114)。本项目采用带 Lebedev 权重的方向集合结构，并把聚合结果送回每个方向：

```text
h_ba = f_theta(x_hat_ba)                   # 每个方向的局部特征，6 维
 g_b = Σ_a w_a h_ba                       # 每个样本的全局特征，6 维
 y_ba = q_eta(concat(h_ba, g_b))           # 每个方向的 φ 或 d
```

这里 `w_a` 为归一化的积分权重。池化仅沿方向轴 `dim=1` 求加权和，`[B,D,6] → [B,1,6]`；随后通过 `expand` 广播成 `[B,D,6]`。因此“全局”是指**一个样本的全部积分方向**，不是整个 batch、整个数据集或整条加载历史。历史信息由输入 λ_max 提供。

- **全局特征具有排列不变性：**将方向记录及其权重一起按任意排列 π 重排，`Σ_a w_π(a) h_b,π(a) = Σ_a w_a h_ba`，所以 g_b 不变（忽略浮点加法顺序误差）。
- **方向输出具有排列等变性：**局部特征跟着方向重排，广播的 g_b 不变，因此 φ、d 的方向列按同一排列重排，而不是每一列数值都保持原位。
- **宏观能量与应力不依赖方向编号：**当前伸长、最大伸长、权重以及物理积分用的 `Dir` 必须同步重排，积分结果才保持一致。只打乱伸长列而保持权重或方向向量不动，会破坏对应关系。当前阶段数据校验要求方向顺序一致，不会自动重排。

这种不变性针对方向元素的编号顺序，不是把 6 个特征通道任意交换，也不等同于任意空间旋转下有限方向积分都严格不变。共享参数也不意味着各方向彼此独立：通过 g_b，一个方向的预测可以依赖同一样本的其他方向；能量求导会包含这条全局特征路径。

### 2.3 从能量到应力
以 `full` 架构为例，下面横向对照神经网络与 MATLAB 的本构数据流。这里的“应变和最大应变”在代码中具体采用**当前方向伸长比 λ 和历史最大方向伸长比 λ_max** 表示。

| 计算环节 | 神经网络数据流（`full`） | MATLAB 理论计算数据流（`full`） |
| --- | --- | --- |
| 当前方向伸长 → 弹性响应 | λ → 自由能模块 → 方向自由能 φ | λ → 弹性链力 `force_chain=(max(λ,1)-1)^3` |
| 历史最大方向伸长 → 损伤响应 | λ_max → 损伤模块 → 损伤 d，剩余比例为 `1-d` | λ_max → 局部剩余比例 → 方向加权平均与局部/全局混合 → `survival_factor` |
| 弹性与损伤响应 → 链力 | `ψ=(1-d)φ` → `W=Σ_a w_a ψ_a` → 自动微分得到加权链力 `∂W/∂λ_a` | 直接按“损伤系数 × 弹性项”计算：`Fc=survival_factor .* force_chain`，再乘积分权重 `w_a` |
| 链力 → 等体积应力 | 加权链力 → 微球积分 → S_bar → Flory 投影 → S_iso | `w_a Fc_a` → 微球积分 → S_bar → Flory 投影 → S_iso |
| 体积比 J → 压力 p | J → J_hat → 体积网络 → U_vol → 自动微分 `p=∂U_vol/∂J` | 直接使用理论公式 `p=k_vol*(J-1)`（即 `p=k*(J-1)`） |
| 压力与等体积应力 → 总应力 | `S_vol=J p C^(-1)` → `S=S_iso+S_vol` → `σ=F S Fᵀ/J` | `S_vol=J p C^(-1)` → `S=S_iso+S_vol` → `σ=F S Fᵀ/J` |

MATLAB 中的“损伤系数”是**损伤后的剩余刚度/能量比例** `survival_factor`（第 5 节记作 `Dmg_chain`），对应网络的 `1-d`，而不是损伤程度 d。其解析计算为：

```text
D_local,a = max((12-max(λ_max,a,1))/12, 0)
D_avg = Σ_a w_a D_local,a
survival_factor_a = (1-α) D_local,a + α D_avg    （默认 α=0.5）
Fc_a = survival_factor_a × (max(λ_a,1)-1)^3
S_bar = Σ_a [w_a Fc_a/λ_a] (n_a⊗n_a)
```

两条路径的主要区别在于**从 λ、λ_max 到链力，以及从 J 到 p 的本构关系如何获得**：MATLAB 显式求值给定的弹性、损伤和压力公式；神经网络学习自由能、损伤与体积能量映射，再通过能量求导得到响应。网络仍保留 `ψ=(1-d)φ` 的损伤耦合结构，以及微球积分、Flory 投影和应力转换等物理运算。由于网络包含方向间的全局特征耦合，加权链力应按 `∂W/∂λ_a` 计算，不能简单视为逐方向独立的 MATLAB 链力公式。

**这正是项目的核心动机：用训练后的神经网络替代上述本构关系中的理论计算部分，以加速软材料本构响应求解，并提高时间与空间（内存/存储）效率。** MATLAB 提供理论参考响应与训练标签，神经网络承担训练后的本构预测。效率提升是项目目标，实际收益需结合推理耗时和内存占用评估，并计入网络求导开销；本节中的简化 MATLAB 公式本身并不意味着神经网络必然更快或更省内存。

神经网络的详细数据流如下（同时保留可选模块与 `forward_sbar()` 分支）：

```text
当前方向伸长 → 自由能模块 → φ ──────────┐
历史最大伸长 → 损伤模块 → d（可选）──────┤
                                      ↓
                     方向能量 ψ = φ 或 (1-d)φ
                                      ↓
                   加权宏观能量 W = Σ w_a ψ_a
                                      ↓ 自动微分 ∂W/∂λ_a
                           加权链力 → 微球积分
                                      ↓
                                    S_bar
                          ┌───────────┴───────────┐
                 forward_sbar()                forward()
                          ↓                       ↓
                   直接输出 S_bar          Flory 投影 → S_iso
                                                  ↑
J → J_hat → 体积网络 → U_vol → p=dU_vol/dJ → S_vol（可选）
                                                  ↓
                                         S = S_iso + S_vol
                                                  ↓
                                         σ = F S Fᵀ / J
```



**微球积分使用 `S_bar = Σ_a [(∂W/∂λ_a)/(λ_a+1e-8)] (n_a⊗n_a)`。导数已经包含能量中的积分权重（总自由能部分已经加权求和），物理层不重复乘权重。投影与体积项为：**

```text
S_iso = J^(-2/3) [S_bar - (C:S_bar) C^(-1)/3]
S_vol = J p C^(-1)    （体积模块关闭时为零）
```

输出六分量排列统一为 `11,22,33,12,13,23`。关闭体积模块时，Cauchy 流程仍执行投影与转换；直接拟合 S_bar 必须使用 `forward_sbar()`。

**运用了自动微分机制对个别物理量求导。**求当前伸长导数时，历史最大伸长作为独立历史变量固定。训练保留能量导数对网络参数的梯度；验证/预测也需要局部自动微分，不能用 `torch.inference_mode()` 禁用能量求导。

### 2.4 物理关系如何嵌入前向计算

本模型训练是一个参数优化问题：优化变量是当前训练模块的权重和偏置，目标函数是第 6.1 节的归一化应力 MSE。已完成模块的参数冻结，不属于后续阶段的优化变量。每个阶段可以写为：

```text
min_theta L(theta) = (1/(6N)) Σ_i Σ_j [(ŷ_ij(theta)-y_ij)/s_j]²
```

这里 ŷ 是整个前向计算输出的应力，Cauchy 流程对应总应力 σ，S_bar 流程对应未投影的 S_bar。物理关系已经包含在预测函数内：

| 嵌入位置 | 前向计算 | 作用 |
| --- | --- | --- |
| 方向能量组合 | ψ_a=(1-d_a)φ_a；无损伤时 ψ_a=φ_a | 用剩余比例调制方向能量 |
| 宏观能量与求导 | W=Σ_a w_a ψ_a，求 ∂W/∂λ_a | 将链力与同一个能量函数关联，求导时固定历史变量 |
| 微球积分 | 按第 2.3 节公式，由方向导数及 n_a⊗n_a 组装 S_bar | 将方向响应转换为宏观应力张量 |
| Flory 投影 | 计算 S_iso | 实现等体积应力投影；理想算术下 C:S_iso=0 |
| 体积能量求导 | p=∂U_vol/∂J，S_vol=J p C^(-1) | 将体积压力与体积自由能关联 |
| 应力度量转换 | σ=F S Fᵀ/J | 将第二类 Piola–Kirchhoff 应力转换为 Cauchy 应力 |

后面三项属于完整 forward() 流程；forward_sbar() 在得到 S_bar 后直接返回。物理层通过自动微分和解析张量运算执行，除浮点误差及代码中的数值稳定项外，这些关系不依赖训练将物理残差逐渐降到零。反向传播继续穿过物理层，将应力误差传回网络参数；它并非训练结束后的后处理。

传统约束优化写成“min L(theta)，满足 g(theta)≤0、h(theta)=0”。本项目没有把上述关系作为独立约束函数交给优化器，也没有在当前应力损失中加入物理残差惩罚项，而是通过前向结构和输出参数化限制可表示的响应，可称为**物理结构嵌入或通过构造施加硬约束**。若使用 L_data + α L_physics 惩罚物理残差，则属于软约束；当前实现不是这种损失形式。这里的硬约束仅指实际嵌入的关系，不代表自动满足所有热力学和材料稳定性条件。

### 2.5 Softplus 与 Sigmoid：性质、选用理由和约束范围

以下 z 为激活前的线性层输出。隐藏层激活用于表达平滑非线性关系；作用于有物理意义的输出时，其取值范围才直接成为相应物理量的约束。局部特征网络末端没有激活函数，6 维特征不要求非负。

**Softplus：用于隐藏层和方向自由能输出。**

当前 nn.Softplus() 对应的理想函数及导数为：

```text
softplus(z) = ln(1+exp(z))
softplus'(z) = sigmoid(z)
softplus''(z) = sigmoid(z) [1-sigmoid(z)] > 0
```

它光滑、严格递增，理论范围为 (0,+∞)；z 很大时近似 z，很小时近似 exp(z)。实际实现使用数值稳定计算；极端输入下，有限精度可能使理论开区间性质不再严格成立。

- **输出层作用：**φ=softplus(z) 将方向自由能限制为非负，且没有人为设置能量上限。
- **为什么用于隐藏层：**模型先对能量求导得到应力，训练还需对应力对网络参数求导。Softplus 的平滑性适合这些导数计算；相比 ReLU 的折点及分段常数的一阶导数，它能表达平滑变化的响应。
- **梯度特性：**正输入较大时导数接近 1，不会像 Sigmoid 一样在正端饱和；负输入很大时导数仍接近 0，不能认为它完全避免了梯度变小。

能量零点可以选取，输出非负是本模型的参数化选择，不能单凭它判定材料稳定。**Softplus 自身凸，不代表整个多层网络对物理输入凸**，因为当前线性层权重没有符号限制。它也不自动保证参考态能量为零、参考态应力为零或正切刚度为正；仅用应力监督通常不能确定能量的加法常数。

**Sigmoid：用于损伤输出。**

```text
d = sigmoid(z) = 1/(1+exp(-z))
sigmoid'(z) = d(1-d)
```

它光滑、严格递增，理论范围为 (0,1)，导数在 z=0 时最大，为 1/4；两端分别趋近 0、1，导数趋近 0。有限 z 在精确算术下不会达到端点，但浮点运算可能舍入到端点。

- **为什么用于损伤：**d 表示从无损伤到完全损伤的程度，Sigmoid 将其限定在相应物理区间，同时使剩余比例 1-d 位于 0 与 1 之间。结合非负 φ，有 0≤ψ=(1-d)φ≤φ，损伤因子不会放大对应方向能量；这不意味着耦合网络的每个应力分量都按同一比例缩小。
- **训练特性：**平滑输出可参与反向传播，但接近 0 或 1 时会饱和，梯度较小，拟合极端损伤值可能较慢。当前末端线性层零初始化给出 d=0.5，这只是初始化，不是参考态损伤条件，也不保证参考态 d=0。
- **保证范围：**Sigmoid 对 z 单调，不代表整个网络对历史最大伸长单调。即使历史最大伸长不减，无符号限制的网络仍可能输出减小的 d。因此，它保证损伤取值范围，**不自动保证损伤不可逆、非负耗散或完整热力学一致性**。若需要这些保证，必须另行构造单调网络、演化律或相应约束。

体积网络末端为线性输出，没有 Softplus 或 Sigmoid 范围约束。当前结构保证 p=∂U_vol/∂J 的导数关系，但不自动保证 U_vol≥0、参考态 p(1)=0 或正体积刚度；隐藏层使用 Softplus 也不会改变这个结论。

## 3. 分阶段训练与最佳模型继承

| 命令参数 | 第 1 阶段 | 第 2 阶段 | 第 3 阶段 | 默认总 epoch |
|---|---|---|---|---:|
| `free_energy` | 只开启、训练自由能 500 epoch | — | — | 500 |
| `free_energy_damage` | 只开启、训练自由能 500 epoch | 继承自由能**最佳权重**，开启损伤，仅训练损伤 500 epoch | — | 1000 |
| `full` | 只开启、训练自由能 500 epoch | 继承自由能**最佳权重**，仅训练损伤 500 epoch | 继承自由能和损伤最佳权重，仅训练体积 500 epoch | 1500 |

**每阶段结束先恢复该阶段最低 loss 对应的权重，再进入下一阶段。已完成模块继续参与前向计算，但参数冻结；后续阶段不能修改其权重和偏置。没有原来的 150 epoch 损伤冻结预热，也没有所有模块联合训练。**

损伤、体积阶段默认也设为 500 epoch，沿用原主训练轮数。可分别通过 `--free-energy-epochs`、`--damage-epochs`、`--volumetric-epochs` 调整。已开启阶段必须至少为 1 epoch，不能跳过尚未训练的前置模块。

### 3.1 相比从头联合训练，为什么分阶段训练

联合训练会同时调整自由能参数 θ_f、损伤参数 θ_d 和体积参数 θ_v。虽然分支参数独立，但损失依赖组合后的总应力；特别是 `ψ=(1-d)φ`，自由能分支的梯度依赖当前损伤，损伤分支的梯度也依赖当前自由能。因此，参数不共享并不表示优化过程没有耦合。

| 关注点 | 从头联合训练可能遇到的问题 | 当前分阶段训练的作用 |
| --- | --- | --- |
| 分支间的梯度耦合 | 自由能和损伤同时变化，使另一个分支正在拟合的响应不断变化 | 冻结已完成分支，每阶段只更新新增分支，避免分支同时更新造成的相互干扰 |
| 分支间的补偿与可辨识性 | 仅从损伤后响应识别 `(1-d)φ`，可能用偏大的 φ 配合偏大的 d 获得相近总应力 | 先用无损伤数据确定自由能响应，再让损伤解释相对已知基准的变化，减少补偿自由度 |
| 分支的物理含义 | 总应力拟合较好，不足以证明自由能、损伤、体积响应分别合理 | 使用对应阶段数据逐个建立和检查无损伤等体积响应、历史相关响应及体积压力响应 |
| 优化尺度与诊断 | 同时优化更多参数，分支尺度、初始化和学习进度可能不同，误差来源不易定位 | 各阶段独立设置学习率、应力尺度和最佳模型选择，便于判断误差出现在哪一步 |
| 已学响应的保留 | 后续训练可能改写已经拟合好的基础响应 | 恢复前阶段最佳权重后冻结，保留该分支已学到的映射 |

这里体积与等体积应力已通过解析投影分开：Cauchy 体积应力为 `pI`，等体积部分在理想算术下迹为零。因此不能把所有分支的耦合都理解为相同的混淆；自由能与损伤的乘法补偿尤其直接，而体积分支的可分离性还来自物理结构本身。

三个阶段仍然用对应数据集的**总 Cauchy 应力**监督，不是分别用 φ、d、U_vol 的真实值直接训练。损伤阶段的自由能保持固定；体积阶段的自由能和损伤保持固定，新增体积分支拟合组合响应中可由体积项解释的部分。冻结参数也不等于切断物理计算图：自由能对当前伸长的求导仍需执行，损伤阶段的应力梯度仍需传回损伤参数。

### 3.2 “各分支物理正确性”的适用范围与代价

分阶段训练有助于使各分支承担预期的物理作用，并分别验证其响应；真正由结构保证的性质来自第 2.4–2.5 节的能量求导、投影和输出范围等。**分阶段训练本身不保证唯一识别真实自由能或真实损伤，也不自动保证损伤不可逆、非负耗散或材料稳定性。** 例如只用应力监督通常无法确定能量加法常数，方向响应也可能存在辨识不充分的问题。

这一策略依赖可靠的阶段数据。前阶段拟合误差会随冻结权重传递到后续阶段；后续模块无法修正已冻结分支，甚至可能在其表达能力允许的范围内吸收部分误差。因而应结合各阶段验证误差和最终组合结果评估，不能预先断言分阶段训练一定比联合训练精度更高或耗时更少。当前实现没有最后的联合微调；上表说明的是采用顺序辨识的机制与动机，并非已完成联合训练对照实验的结论。

## 4. 初始化、输入归一化与超参数

### 4.1 参数初始化

- 普通线性层权重使用 Xavier normal，偏置为 0。
- 损伤预测器最后一个线性层的权重与偏置再置零，首次启用时 `d=sigmoid(0)=0.5`。自由能阶段完全绕过损伤，不会乘以 0.5。
- 体积网络最后一个线性层权重与偏置再置零，首次启用时 `U_vol=0`、`p=0`。
- 三个模块在模型构造时仅初始化一次。阶段切换恢复最佳权重，冻结已完成模块，不重新初始化。

#### 4.1.1 Xavier normal 是什么

**Xavier normal（也称 Glorot 正态初始化）是一种按网络层宽度确定随机权重尺度的方法。** Xavier 来自 Xavier Glorot 的名字，normal 指正态分布；它不是输入归一化，也不是训练中的优化算法。当前代码调用 `nn.init.xavier_normal_(module.weight)`，使用默认 `gain=1`，对各权重元素按下式采样：

```text
W_ij ~ Normal(0, std²)
std = gain × sqrt(2 / (fan_in + fan_out))
```

`fan_in` 是该线性层的输入特征数，`fan_out` 是输出特征数。例如 `32 → 32` 层的标准差为 `sqrt(2/64)≈0.1768`；`1 → 32` 层为 `sqrt(2/33)≈0.2462`。这些数字只由该层宽度和 gain 决定，与 batch size、积分方向数无关。函数名末尾的下划线表示直接修改传入的权重张量。定义及公式见 [PyTorch 初始化文档](https://docs.pytorch.org/docs/stable/nn.init.html#torch.nn.init.xavier_normal_)。

#### 4.1.2 为什么普通权重随机初始化、偏置置零

对于一层 `z=Wx+b`，若权重过大，层间信号和梯度可能被放大，或使激活函数进入梯度很小的区域；若过小，信号和梯度可能逐层衰减。Xavier 的设计在一定独立性、均值及近似线性假设下，折中考虑前向传播和反向传播的方差尺度，使初始权重随层宽变化，而非所有层都使用任意固定标准差。

随机权重还用于打破同层神经元的对称性，使不同神经元可以学习不同特征。偏置初始化为 0，则是不额外加入初始偏移；由于权重已经随机，偏置为 0 不会使整个网络都成为相同神经元。Softplus 在 0 处本身不为 0，所以“偏置为 0”也不表示隐藏特征或自由能输出为 0。

本项目使用 Softplus，并通过能量导数拟合应力，初始输出及导数的尺度会影响训练。Xavier 是当前采用的通用起点，**不保证 Softplus 网络各层方差严格不变，也不保证梯度永不消失或爆炸**；代码没有为 Softplus 另设 gain。初始化、输入归一化与 Adam 分别负责初始参数尺度、输入尺度和训练中的参数更新，三者作用不同。

#### 4.1.3 为什么损伤和体积网络的最后一层再置零

代码先为所有线性层执行 Xavier 初始化，再覆盖损伤预测器和体积网络的最后一个线性层，将其权重、偏置都置为 0。仅末层置零，前面的特征网络仍保留随机权重。以下是这种设置在当前结构中的作用，并不表示已通过对照实验证明它最优。

| 分支 | 初始输出 | 这样设置的作用与边界 |
| --- | --- | --- |
| 损伤 | 最后线性输出 z=0，故所有方向 `d=sigmoid(0)=0.5` | 给出一致的初始损伤；Sigmoid 在 z=0 的导数为 1/4，避开输出端的初始饱和。但这不是无损伤初值，启用损伤时剩余能量比例为 0.5 |
| 体积 | 对所有 J 有 `U_vol=0`，故 `p=∂U_vol/∂J=0` | 体积分支启用时从零压力贡献开始，避免一开始叠加随机体积应力；尤其体积输入包含 `1/delta_J_ref` 的求导尺度。它不是训练结束后的压力约束 |

自由能阶段完全绕过损伤分支，因此其初始 d=0.5 不影响首阶段。进入损伤阶段时，预测响应可能相对上一阶段发生跳变；末层置零并不保证阶段切换时总应力连续。若希望损伤从接近 0 开始，需要改变初始化设置，但靠近 Sigmoid 端点又会使其导数变小；当前实现保留中间值初始状态。

**末层为零仍然可以开始学习。** 写作 `z=wᵀh(x)+b` 时，初始 w=0 会使通过这一分支传给前面隐藏参数的梯度为零，但末层权重的梯度不必为零；末层更新为非零后，梯度便可继续传到隐藏层。对于体积应力监督，`p=Σ_j w_j ∂h_j/∂J`，即使初始 p=0，也有 `∂p/∂w_j=∂h_j/∂J`，所以末层权重仍可获得训练信号。体积末层的常数偏置在对 J 求导时消失，单靠当前应力损失无法识别这个能量常数。

这与把所有层权重都设成 0 不同；后者会失去随机特征带来的神经元差异，并可能阻断有效学习。自由能分支末层保留 Xavier 权重，使首阶段从随输入变化的能量及导数开始。三个分支仅在模型创建时初始化一次，后续继承最佳权重，不在阶段切换时重新随机采样。

### 4.2 输入归一化

当前和历史最大方向伸长共用 `x_hat=(x-mean)/(std+1e-8)`；统计量在自由能阶段确定，后续固定，避免继承权重后自由能函数发生变化。

| 流程 | mean / std 来源 |
| --- | --- |
| `train4.py` | 首阶段 MAT 的完整当前方向伸长数据；标准差为零时设为 1 |
| `train_sbar.py` | 无损伤数据划分后的训练子集；继承检查点时恢复已保存的统计量和划分 |

体积输入单独使用 `J_hat=(J-1)/delta_J_ref`，默认 `delta_J_ref=1e-4`。压力是对原始 J 求导，自动微分包含归一化的链式法则。

输入统计量与应力损失尺度是两件事：前者固定，后者在每阶段根据该阶段训练子集重新计算。

### 4.4 Adam 与普通小批量梯度下降的区别

**“小批量”描述每次使用哪些数据计算梯度，“Adam”描述得到梯度后如何更新参数。** 两者并不互斥。本项目的准确表述是“采用基于小批量梯度的 Adam 优化”。下文的普通小批量梯度下降特指不带动量的 mini-batch SGD。

设 theta 为当前可训练参数，B_t 为第 t 次更新所用批次，L_Bt 为该批次平均损失。两种算法都通过反向传播计算当前批次梯度：

```text
g_t = ∇_theta L_Bt(theta_(t-1))
```

**普通小批量梯度下降（无动量 SGD）：**

```text
theta_t = theta_(t-1) - eta_t g_t
```

它直接沿当前批次梯度的反方向更新。在统一学习率下，各参数梯度都乘相同的 eta_t，梯度大的参数更新幅度大，梯度小的参数更新幅度小。学习率可以随训练轮数衰减，但这个更新规则本身不记录历史梯度。

**Adam：记录梯度一阶矩和二阶原始矩的指数移动平均。**

```text
m_0 = 0, v_0 = 0
m_t = beta1 m_(t-1) + (1-beta1) g_t
v_t = beta2 v_(t-1) + (1-beta2) g_t²
m_hat_t = m_t / (1-beta1^t)
v_hat_t = v_t / (1-beta2^t)
theta_t = theta_(t-1) - eta_t m_hat_t / (sqrt(v_hat_t)+epsilon)
```

平方、开方、除法均按参数分量逐元素计算。beta1、beta2 是控制历史记忆衰减速度的系数，越接近 1，历史平均变化越慢。

- m_t 平滑梯度方向，起类似动量的作用，使更新参考近期趋势。
- v_t 跟踪梯度平方的量级，用于逐参数调整更新尺度；它不是 Hessian，也不是减去均值后的方差。
- m、v 从零初始化，前期估计偏向零，因此用带帽量进行偏差修正。
- epsilon 避免分母过小；eta_t 仍是需要设置和调度的全局学习率。

直观地说，Adam 同时考虑“近期梯度主要指向哪里”和“这个参数近期梯度的量级有多大”。历史梯度平方较大的坐标，分母会压低更新尺度；实际步长还取决于分子中的历史梯度，不能简单理解为裁剪所有大梯度。

| 比较项 | 普通小批量 SGD（无动量） | Adam |
| --- | --- | --- |
| 梯度来源 | 当前小批量 | 当前小批量 |
| 更新方向信息 | 当前梯度 | 当前与历史梯度的一阶矩 |
| 各参数更新尺度 | 统一学习率乘各自梯度 | 全局学习率结合各参数二阶矩调整 |
| 额外历史状态 | 无动量状态 | 每个参数保存 m、v 两组状态 |
| 对本项目的意义 | 规则简单，需要合适的学习率 | 可缓和参数梯度量级差异及批次噪声对更新的影响 |

本模型通过能量导数拟合应力，不同层和参数可能有不同的梯度尺度，因此 Adam 的历史平滑与逐参数缩放具有实用价值。但 Adam 不保证每批损失下降、不保证全局最优，也不保证泛化一定优于 SGD；效果仍需验证集及测试集评估。

当前代码为 optim.Adam(model.stage_parameters(stage), lr=...)。**每个新阶段重新创建优化器，因此 m、v 和更新计数从头开始；已完成模块继承最佳权重并冻结。** StepLR 按 epoch 降低全局学习率 eta，Adam 则在每次更新时利用历史梯度调整各坐标尺度，两者共同决定更新。公式中的 t 是本阶段的批次更新次数，不是 epoch 数。

## 5. 阶段数据与合成标签

在 MATLAB 中先运行一次（项目根目录为当前目录）：

```matlab
run('matlab_data_generation/generate_all_datasets.m')
```

这会生成三套数据，每套含七工况训练集与五工况测试集：

```text
matlab_data_generation/generated/
  free_energy/train_7cases.mat
  free_energy/test_5cases.mat
  free_energy_damage/train_7cases.mat
  free_energy_damage/test_5cases.mat
  full/train_7cases.mat
  full/test_5cases.mat
```

阶段数据选择固定为：自由能阶段读取 `free_energy`；损伤阶段读取 `free_energy_damage`；体积阶段读取 `full`。例如 `--architecture full` 会依次读取三套训练数据，不能三个阶段都用含损伤与体积项的 full 标签。

| 数据模式 | 链力 Fc | 运动学 | 压力与体积应力 |
|---|---|---|---|
| `free_energy` | `Fc = force_chain` | `F=F_bar, J=1` | 不计算 p、S_vol 的本构公式 |
| `free_energy_damage` | `Fc = Dmg_chain .* force_chain` | `F=F_bar, J=1` | 不计算 p、S_vol 的本构公式 |
| `full` | `Fc = Dmg_chain .* force_chain` | `F=F_bar*F_vol`，J 按原路径变化 | `p=k_vol*(J-1)`，`S_vol=J*p*Cinv` |

公共链力公式是 `force_chain=(max(LS,1)-1).^3`。仅开启损伤时计算：

```matlab
D_local = max((12.0 - max(LS_max, 1.0))/12.0, 0.0);
D_avg = sum(Wt .* D_local);
Dmg_chain = (1.0-alpha)*D_local + alpha*D_avg;
Fc = Dmg_chain .* force_chain;
```

公式中的 `Dmg_chain` 实际表示剩余刚度/能量比例，对应网络的 `(1-d)`，并非网络输出的损伤 d。`alpha=0.5` 保持不变。纯自由能分支不计算这些损伤公式，直接 `Fc=force_chain`。

**前两种数据也不调用体积变形函数，**不计算 `k_vol*(J-1)` 或 `J*p*Cinv`，总应力直接取等体积分量。为保持 MAT 接口统一，仍导出值为 0 的压力字段；纯自由能的历史最大伸长字段为全 1 占位，不参与模型计算。`delta_J_ref=1e-4` 作为固定参考尺度保留，只有 full 保存和使用 `k_vol=1e6`。

旧版前两种数据虽然 p=0，**但 J 仍随加载变化；不符合当前严格等体积路径**，必须重新生成。Python 会检查模块组合、J、字段形状与阶段间方向/权重/参考尺度，避免静默误用。

更多 MATLAB 入口见 [数据生成说明](matlab_data_generation/README.md)。

### 5.1 先区分：空间维度、物理张量阶数和数组维数

这里始终描述三维空间中的材料。F、C、S、σ 是二阶物理张量，单个状态可写成 `3×3` 矩阵。把 N 个这样的矩阵叠起来，得到三维数组 `[3,3,N]` 或 `[N,3,3]`；把每个矩阵的分量存成一行，得到二维数组 `[N,9]` 或 `[N,6]`。**这类“3D → 2D”是数据存储形状转换，不是把三维材料变成二维材料，也不是降成平面应力或平面应变问题。** 神经网络的 `[B,D,6]` 则是“样本、积分方向、特征通道”三条轴，与空间坐标轴不同。

下文 T 表示一个工况的加载步数，N 表示多个工况合并后的总样本数，B 表示实际 batch 大小，D 表示积分方向数（默认 110）。

### 5.2 MATLAB：逐页物理计算 → 二维样本表 → MAT

对应 `matlab_data_generation/common/generate_polymer_dataset.m` 的 `evaluate_case`、`sphere_integration_matrix`、两个 `tensor_pages_to_*` 辅助函数和 `assemble_results`。

| 数据 | 单工况内部形状 | 转换操作 | 合并后训练 MAT 字段及形状 |
| --- | --- | --- | --- |
| 当前方向伸长 | `La_Dir: [D,T]` | 转置为 `[T,D]`，按工况竖直拼接 | `X_La_curr_export: [N,D]` |
| 历史最大方向伸长 | `La_Dir_max: [D,T]` | 同上 | `X_La_max_export: [N,D]` |
| 体积比 J、压力 p | `[1,1,T]` | `reshape(...,[],1)` 得 `[T,1]`，再拼接 | `X_J_export`、`Y_p_export: [N,1]` |
| C | `C_dfm: [3,3,T]` | 取六个独立分量得到 `[6,T]`，再转置 | `X_C_export: [N,6]` |
| F | `F_dfm: [3,3,T]` | 按指定顺序取全部分量得到 `[9,T]`，再转置 | `X_F_export: [N,9]` |
| S、σ | `[3,3,T]` | 取六个独立分量得到 `[6,T]`，再转置 | `Y_Stotal_export`、`Y_sigma_total_export: [N,6]` |

`F_bar`、`F_vol`、`C_bar` 也使用 `[3,3,T]` 页式表示，`pagemtimes` 沿每个加载步进行矩阵运算。方向向量 `Dir` 为 `[D,3]`，权重 `Wt` 为 `[D,1]`。每一步计算 `λ_a=sqrt(n_aᵀ C_bar n_a)`；启用损伤时，逐方向递推 `λ_max,a(t)=max(λ_max,a(t-1),λ_a(t))`，第一步与 1 取最大值。无损伤数据的最大伸长为全 1 占位。

注意方向伸长来自等体积的 `C_bar`，导出的 `X_C_export` 却是完整的 `C_dfm=FᵀF`，用于后续 Flory 投影。每个工况先独立计算历史，再沿样本轴 `vertcat` 拼接，因此历史不会跨工况累积；工况长度单独保存在 `Train_Case_Lengths`。测试字段使用 `_test` 后缀及 `Case_Lengths`，核心数据形状相同。

### 5.3 Python：读取样本表 → batch → 特征网络

`data.py` 的 `scipy.io.loadmat` 直接读取上述二维表，不需要把 `[N,D]` 再转置。`training.py` 同步划分各字段，再用 `TensorDataset` / `DataLoader` 沿第一轴抽取样本：

```text
完整数据：[N,D], [N,D], [N,1], [N,6], [N,9], [N,6]
一个 batch：[B,D], [B,D], [B,1], [B,6], [B,9], [B,6]
字段顺序：λ_current, λ_maximum, J, C, F, σ_label
```

训练会打乱样本顺序，但每行已经携带在原始加载路径上计算好的历史最大伸长；Python 不沿打乱后的 batch 重新累计历史。J 读取为 float64，其他核心输入和应力标签为 float32；体积网络先计算 `(J-1)/delta_J_ref` 再转为网络输入类型，以保留接近 1 的微小体积变化。

`networks.py` 的实际形状变化为：

| 步骤 | 形状变化 | 含义 |
| --- | --- | --- |
| 展开方向标量 | `[B,D] → [B×D,1]` | 把每个样本的每个方向作为共享 MLP 的一行输入 |
| 提取局部特征 | `[B×D,1] → [B×D,6] → [B,D,6]` | 恢复样本和方向轴，保留对应关系 |
| 加权方向池化 | `[B,D,6] × [1,D,1] → [B,1,6]` | 沿 D 求和，不沿 B 求和 |
| 广播并拼接 | `[B,1,6] → [B,D,6]`；再与局部特征拼为 `[B,D,12]` | 每个方向同时看到自己的局部特征与本样本的全局特征 |
| 方向预测 | `[B,D,12] → [B×D,12] → [B×D,1] → [B,D]` | 输出每个方向的 φ 或 d |
| 能量及导数 | `[B,D] → W:[B,1] → ∂W/∂λ:[B,D]` | 加权积分后，对原始当前伸长求导 |

例如 `B=256,D=110` 时，提取器处理 `[28160,1]`，输出恢复为 `[256,110,6]`；全局池化结果为 `[256,1,6]`。这不表示把 28160 个输入拼成一个长向量，也没有创建 28160 套网络。最后一个 batch 的 B 可以小于 256。

### 5.4 Python 物理层：六分量向量 ↔ 批量 3×3 矩阵

`physics.py` 为矩阵求逆、缩并和乘法恢复矩阵形状，为模块接口与应力损失再转回向量：

```text
方向导数及伸长 [B,D]
  → term [B,D,1,1] × 方向并矢 [1,D,3,3]
  → 方向应力贡献 [B,D,3,3]
  → 沿方向求和 [B,3,3]
  → S_bar 六分量 [B,6]
  → Flory 层：S_bar、C 各恢复 [B,3,3]，J/p 广播为 [B,1,1]
  → S_total、S_iso、S_vol 各输出 [B,6]
  → Cauchy 层：S 恢复 [B,3,3]，F 从 [B,9] 恢复 [B,3,3]
  → σ=F S Fᵀ/J 得 [B,3,3]
  → σ 六分量 [B,6]，与标签计算损失
```

对称张量统一使用 `[11,22,33,12,13,23]`。六分量不是直接 `reshape` 成 `3×3`，而是由 `stress_vec_to_mat` 把非对角分量补到对称位置：

```text
[v11,v22,v33,v12,v13,v23] ↔ [[v11,v12,v13],
                            [v12,v22,v23],
                            [v13,v23,v33]]
```

这里剪切项是张量分量本身，没有工程剪切应变中的倍数 2。F 一般不对称，必须保留全部九个分量，按 `[F11,F12,F13,F21,F22,F23,F31,F32,F33]` 排列；Python 才能直接 `reshape(-1,3,3)`。MATLAB 虽然默认按列处理线性索引，但本项目导出函数显式按上述行顺序取值，不能用未经核对的 MATLAB `reshape(F,9,[])` 替代。

因此，MATLAB 的 `[3,3,T] → [T,6/9]` 主要用于导出；Python 的 `[B,6/9] ↔ [B,3,3]` 用于物理运算；网络的 `[B,D,K] ↔ [B×D,K]` 用于批量调用共享 MLP。它们都保留相应元素的对应关系，而方向池化 `[B,D,6] → [B,1,6]` 才是对方向信息的聚合，不能看作可逆 reshape。

## 6. 归一化 MSE、RMSE 与相对误差

以下令 `y_ij` 为真实应力、`ŷ_ij` 为预测应力，i 是样本、j 是六个应力分量。Cauchy 流程使用总应力 σ，S_bar 流程使用 S_bar 标签，公式相同。

### 6.1 训练损失：逐分量 RMS 归一化 MSE

每阶段只用自己的训练子集计算标签尺度；验证沿用相同尺度：

```text
r_j = sqrt(mean_train(y_ij²))                         # 标签 RMS
floor = max(1e-4 × max(max_j(r_j), 1e-8), 1e-8)
s_j = max(r_j, floor)
L = (1/(6N)) Σ_i Σ_j [(ŷ_ij-y_ij)/s_j]²              # 归一化 MSE
```

尺度下限防止零应力或接近机器零的剪切分量被过度放大。模型直接输出应力，归一化仅用于计算损失，不需要对预测结果再乘尺度“反归一化”。

默认以验证集 L 选择最佳模型，**并未把训练目标改成 RMSE**。不同阶段的标签、尺度不同，loss 不跨阶段比较。

### 6.2 评估：原始应力 MSE 与逐分量 RMSE

```text
MSE_j = (1/N) Σ_i (ŷ_ij-y_ij)²
RMSE_j = sqrt(MSE_j)
MSE_all = (1/6) Σ_j MSE_j
RMSE_all = sqrt(MSE_all) = sqrt((1/6) Σ_j RMSE_j²)
```

`pred2.py` 报告六分量合并的 `MSE_all` 与六个 `RMSE_j`；`RMSE_all` 是由 MSE 可推导的指标，当前并不单独导出。MSE 的单位为应力单位的平方，RMSE 与 MAT 标签的应力单位相同；不能直接把 `sqrt(L)` 当作原始应力 RMSE。

对同一固定模型、同一批评估样本和相同尺度，有：

```text
L = (1/6) Σ_j (RMSE_j/s_j)²
```

只有掌握逐分量归一化 MSE，才能分别通过 `RMSE_j=s_j×sqrt(L_j)` 还原；一个合并 L 无法反推出六个 RMSE。训练图中的批次平均 loss 混合了更新过程中的多份权重，也不能直接套用此关系换算最终模型 RMSE。

### 6.3 S_bar 的相对 L2

S_bar 还报告三个正应力分量合并的相对 L2：

```text
normal_relative_l2 = ||ŷ[:,0:3]-y[:,0:3]||_F / max(||y[:,0:3]||_F, 1e-12)
百分比误差 = 100 × normal_relative_l2
```

它是三个正应力合并后的误差范数比例，并非三个分量相对误差的算术平均。`normal_component_relative_l2` 则逐正应力分量计算 `RMSE_j/max(RMS_j,1e-12)`，这里 RMS 取自当前评估样本。近零剪切分量主要观察 RMSE 和最大绝对误差。

## 7. 检查点、输出曲线与预测评估

### 7.1 最佳模型与保存规则

默认以每个 epoch 完成后的验证集归一化 MSE 为 loss 选择标准。需要按训练集 loss 选择时，添加：

```powershell
python train4.py --architecture full --selection-loss train
```

`train` 模式会在每个 epoch 更新结束后重新评估整个训练子集，保证比较的 loss 和保存的权重来自同一时刻，而非不同 batch 更新过程中混合的 loss。

**每阶段单独选择最佳 epoch，不跨阶段比较 loss**（标签、归一化尺度不同）。最优规则采用严格小于；相同 loss 保留最早达到的 epoch。

- 前置阶段**最佳状态仅暂存在内存，用于恢复与继承，不另存阶段模型**。
- 最终阶段每当 loss 改善，原子覆盖唯一的 `model.pth`。最后一个 epoch 不是最优时，不覆盖最佳模型。
- **训练结束恢复最终阶段最佳权重，再生成训练应力曲线和预测结果，确保图与检查点对应**。
- 不保存逐 epoch 模型，也不保存 last 模型。检查点中包含三个模块的参数、最终开关、归一化、每阶段最佳 epoch/loss、训练配置及数据路径。
- 关闭的模块在检查点中仍为未训练的初始权重。最终阶段尚未开始前中断，不会生成本次训练的新模型文件。

默认输出：

```text
outputs/<architecture>/
  model.pth                  # 唯一最终组合最佳模型
  training_history.json      # 各 epoch train/validation loss、学习率和阶段最佳记录
  train_loss_curve.png        # 阶段边界和最佳 epoch 标记
  train_components.mat
  train_case_1.png ... train_case_7.png
  prediction/
    prediction_components.mat
    test_case_1_pred.png ... test_case_5_pred.png
```

损失曲线的 Train Loss 在默认 validation 模式下是该 epoch 的训练批次平均值；验证集 loss 用于最佳选择。切换 `train` 选择时，Train Loss 是更新结束后重新评估的值。

旧版检查点可经 `restore_checkpoint` 映射旧参数名用于预测，但这不表示它们已按新流程训练。已有 `outputs/` 的旧模型、图像不会因修改源码自动更新；需要运行新训练命令。使用其他 `--output-dir` 可以保留旧实验。

训练参数 `--checkpoint` 指定检查点保存位置，不是断点续训入口。最终阶段开始前中断不会生成本次的新检查点；复用输出目录时已有旧文件可能仍在，因此每次实验宜使用独立 `--output-dir`。

### 7.2 曲线中的样本与预测顺序

`train4.py` 训练结束恢复最终阶段最佳模型，按原始 MAT 顺序分批预测完整阶段数据，曲线同时包含内部训练点和验证点。训练批次会打乱，导出曲线不会按训练 DataLoader 顺序拼接。第七训练工况及对应预拉伸测试工况的图会截取后续加载段，完整预测数组仍保留原始样本。

模型做逐样本本构预测：最大方向伸长由输入提供，不使用上一步预测应力递推下一步。全量曲线用于观察拟合；`pred2.py` 加载检查点并预测独立指定的测试 MAT，用于测试评估。标签只用于监督、对照和误差计算，不作为应力预测输入。

```bash
python -m unittest discover -s tests -v
```

测试覆盖模块结构、初始化与开关、冻结和最佳权重继承、检查点保存与恢复，以及数据与解析公式的一致性。数据相关测试依赖生成的 MAT 文件。测试用于验证实现行为，不替代完整训练后的收敛与泛化评估。

### 8.2 常见问题

- **找不到 MAT 文件**：先运行 MATLAB 批量生成脚本，或通过数据路径参数指定文件。
- **架构或 `J` 校验失败**：确认使用与阶段匹配的数据。旧版前两种数据可能含体积变化，需要重新生成。
- **预测时找不到模型**：先完成对应配置的训练，或通过 `--checkpoint` 指定已保存模型。
- **CUDA 不可用**：使用 `--device cpu` 运行；若需要 GPU，检查本地 PyTorch 的 CUDA 支持。

合成数据的更多 MATLAB 入口与字段说明见 [MATLAB 数据生成说明](matlab_data_generation/README.md)。双轴 S_bar 数据请使用 [S_bar 训练指南](README_Sbar训练.md) 中的专属入口。
